# Análise Discriminante

Repositório acadêmico com dados e códigos relacionados à **Análise Discriminante de Fisher**.

## Objetivo

Explorar métodos supervisionados de classificação que buscam combinações de variáveis capazes de discriminar grupos previamente definidos.

## Pontos de atenção

- Verificar pressupostos e estrutura dos grupos.
- Avaliar escalas e correlações entre variáveis.
- Separar adequadamente dados de treinamento e avaliação.
- Interpretar funções discriminantes e taxas de classificação no contexto da amostra.

Consulte os arquivos do repositório para identificar os dados e procedimentos efetivamente utilizados. Material didático, não uma solução de classificação validada para uso operacional.
